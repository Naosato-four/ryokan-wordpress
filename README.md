
# 旅館サイト（WordPress化）

## 概要

チーム制作で架空の旅館をテーマに制作したWebサイトです。

デザインからHTML/CSSによるコーディングをAIを使用して行い、その後WordPress化を実施しました。
静的HTMLで制作したサイトをWordPressテーマへ移行し、管理画面から更新できる構成にしています。
私は主にサイト全体のWordpress化を担当しました。

## 使用技術

- HTML5
- CSS3
- JavaScript
- PHP
- WordPress
- Google AI Studio
- ChatGPT
- Google Gemini（画像もGeminiで作成しております）
- Copilot

## 実装内容

- オリジナルデザイン制作
- レスポンシブ対応
- WordPressテーマ化
- 固定ページの作成
- 投稿機能（お知らせ）の実装
- お問い合わせフォームの設置
- PHPテンプレートによる共通パーツの管理

## 工夫した点

- 旅館らしい落ち着いた雰囲気を意識し、余白や配色、写真の見せ方を工夫しました。
- ヘッダーやフッターなどの共通部分をPHPテンプレートとして分割し、保守性を高めました。
- 静的HTMLをWordPressへ移行する過程で、テンプレート階層やWordPressの仕組みを理解しながら実装しました。
- 管理画面からお知らせを更新できるようにし、運用しやすいサイトを目指しました。
